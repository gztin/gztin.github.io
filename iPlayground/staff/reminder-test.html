iPhone

SAFARI
  1. 使用 Safari 開啟本頁。
  2. 點選瀏覽器下方的分享按鈕。
  3. 向下找到並點選加入主畫面。
  4. 確認名稱為「iPlayground 任務助手」，再點選加入。
  5. 從手機桌面開啟任務助手，打開提醒並允許通知。

Android

CHROME
  1. 使用 Chrome 開啟本頁。
  2. 點選右上角的更多選單（⋮）。
  3. 選擇安裝應用程式或加到主畫面。
  4. 依畫面指示確認安裝或新增捷徑。
  5. 從手機桌面開啟任務助手，打開提醒並允許通知。
