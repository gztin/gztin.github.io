# 星野夏令營行前會議紀錄（展示範例）

> 本文件僅供介面與流程展示，所有人名、地點、活動及分工均為虛構。

## 一、活動資訊

- 活動日期：第一日至第三日。
- 集合時間：首日上午 08:00，工作人員提前 30 分鐘完成報到。
- 集合地點：星野營地營本部草地。
- 雨天集合點：自然教室前廊。
- 每位工作人員應攜帶識別證、雨具、水壺及個人常備藥品。

## 二、營地配置與器材

- 器材組於活動前一日晚間完成帳篷區、集合區及手作教室檢查。
- 確認營繩、營釘、照明、廣播設備與備用電池數量。
- 飲水站、急救箱與滅火器應設置在容易辨識且不阻礙動線的位置。
- 活動道具依小隊顏色分類，使用後由關主清點並放回指定收納箱。

## 三、報到與小隊引導

- 營隊服務站負責學員報到、名牌及活動手冊發放。
- 小隊隊輔在集合區迎接學員，完成點名後帶領認識營地。
- 學員若有飲食、藥物或行動需求，由隊輔記錄並交由營務組統一處理。
- 接送人員只能在指定區域停留，避免影響器材搬運及緊急通道。

## 四、活動流程

- 每項活動開始前 10 分鐘，由活動引導確認人數、器材及場地安全。
- 活動講師抵達後先至營隊服務站報到，再由活動組陪同前往場地。
- 隊輔負責小隊移動與秩序；器材問題交由器材組處理。
- 活動結束後先清點學員，再進行器材回收與下一場交接。

## 五、餐食與飲水

- 餐務組確認葷食、素食及特殊餐點數量，依小隊分區領取。
- 用餐前提醒學員洗手；用餐後完成廚餘、回收物與一般垃圾分類。
- 飲水站每小時巡查一次，發現地面積水應立即擦乾並放置提醒標示。
- 食物不得留在帳篷內，避免吸引昆蟲或野生動物。

## 六、夜間與雨天備案

- 夜間活動開始前確認頭燈、照明及回程路線。
- 晚點名後由隊輔回報人數，熄燈後安排營區安全巡查。
- 遇雷雨或強風時，戶外活動移至自然教室，並停止使用金屬器材。
- 若天候達到撤離標準，由營務組廣播集合並依小隊順序移動。

## 七、安全與緊急通報

- 發現受傷、走失或身體不適時，先確保現場安全並通知醫護站。
- 非醫護人員不得自行給藥；學員自備藥品由指定人員依紀錄協助。
- 緊急事件由營隊協調統一聯繫家長與外部單位。
- 所有異常狀況均需記錄時間、地點、處理經過及交接人員。

## 八、撤場與環境復原

- 各組依清單歸還器材，缺件或損壞應立即登記。
- 完成垃圾分類、帳篷區巡查及公共空間清潔。
- 小隊隊輔確認學員皆由指定接送人員接回。
- 最後離場前由營務組進行總巡查，落實無痕營地原則。

## 九、範例支線任務

| 支線任務 | 任務說明 |
| --- | --- |
| 完成營地安全巡查 | 確認集合點、照明及急救箱位置並向營務組回報。 |
| 尋找三種特色葉片 | 觀察三種不同形狀的落葉，記錄特徵後帶回小隊分享。 |
| 補充飲水站 | 確認飲水與環保杯數量，保持周邊地面乾燥。 |
| 拍攝今日小隊合照 | 在指定活動區完成團體照，避開未同意入鏡的人員。 |
| 募集營火歌曲 | 向三個小隊蒐集歌曲提案並交給活動組。 |
| 確認緊急集合點 | 走訪三個集合點，確認標示及通道保持暢通。 |
| 新學員營地導覽 | 介紹服務站、飲水區、洗手間與集合草地。 |
| 帳篷繩結檢查 | 抽查營繩與營釘，發現鬆脫時通知器材組。 |
| 記錄今晚星空 | 記錄兩個星座或亮星，在晚間分享時間介紹。 |
| 整理闖關道具 | 依關卡標籤分類道具並登記缺件。 |
| 回收散落名牌 | 巡視集合區與活動區，將拾獲名牌送至服務站。 |
| 蒐集露營小技巧 | 訪問一位隊輔並在小隊時間分享一項技巧。 |
| 完成無痕營地任務 | 檢查責任區的垃圾分類與地面狀況，恢復場地原貌。 |
