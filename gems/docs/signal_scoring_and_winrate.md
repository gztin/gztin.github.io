# 訊號評分與達標評估系統

本文件詳細說明 Gems 訊號情報系統的評分邏輯、推送階段以及「已達標」的判定標準。

## 1. 評分模型（0-100）
所有訊號的分數皆根據多個技術分量進行權衡，最終限制在 `0..100`。

### 核心分量指標：
- **momentum15**：15m 週期之布林位置與趨勢動能。
- **momentum1h**：1h 週期之長線動能狀態。
- **volumeStrength**：15m 成交量相對前 20 根均量的爆發強度。
- **structureStrength**：價格結構分數（包含 R2、斜率、Higher-Lows）。
- **reversalStrength**：反轉強度（急跌幅度、反彈力道、收復比例）。

### 推送門檻：
- **基礎級 (60+)**：符合基本強勢邏輯。
- **優質級 (70+)**：具備較好的量價配合。
- **精選級 (80+)**：多週期共振，勝率較高。
- **極致級 (90+)**：罕見的爆發型強勢訊號。

---

## 2. 訊號推送階段 (Notification Stages)
為了追蹤訊號的後續表現，系統採用四段式追蹤推送：

| 階段 | 時間點 | 說明 |
| :--- | :--- | :--- |
| **Stage 0** | **0m (立即)** | 首次發現訊號，立即推送並記錄進場價。 |
| **Stage 1** | **15m** | 再次推送，顯示當前獲利空間。 |
| **Stage 2** | **30m** | 再次推送，顯示當前獲利空間。 |
| **Stage 3** | **1h** | 再次推送，顯示當前獲利空間。 |
| **Stage 4** | **4h** | 最終追蹤推送，完成訊號生命週期。 |

> **註：** 系統具備「持久化追蹤」功能，即便重啟，也會自動銜接上述時間點。

---

## 3. 「已達標 (Passed)」判定標準
系統會在不同時間點評估訊號是否成功衝過指定的漲幅門檻：

| 評估週期 | 達標門檻 (漲幅 %) | 意義 |
| :--- | :--- | :--- |
| **15m** | **+ 0.8%** | 極短線快速脫離成本區。 |
| **30m** | **+ 1.5%** | 短線波段獲利。 |
| **1h** | **+ 5.0%** | 中線趨勢確立。 |
| **2h** | **+ 15.0%** | 強勢主升段。 |
| **4h** | **+ 25.0%** | 翻倍級/爆發型行情。 |

**判定邏輯：**
*   系統會抓取訊號進場後對應時長（例如 1 小時後）的實際收盤價。
*   計算 `((目前價格 - 進場價) / 進場價) * 100`。
*   若 >= 門檻則標記為 **Pass (已達標)**，否則為 **Fail**。
*   未滿時長則標記為 **Pending (評估中)**。

## 4. 數據儲存
- **實時紀錄**：`public/api/signal_journal.json` (提供給儀表板使用)
- **歷史日誌**：`data/signal_history.ndjson` (用於長期回測與統計)
