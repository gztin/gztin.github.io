# 進場策略（Entry Strategy）

整合主流幣掃描、時框過濾、形態判讀、指標共振的完整進場邏輯。

> 最後更新：2026-04 優化版（v3）
> 優化項目：4h 加回 EMA89 結構確認、Stage1 門檻提高至 5 分、SL 距離上限收緊至 4%、加入錨點過濾

---

## 一、掃描架構

**Loop A** — 主流幣掃描（BTC / ETH / XAU / OIL100）
- 頻率：每 1 秒
- 幣種：BTC、ETH、XAU（黃金）、OIL100（原油）（固定，不掃排行榜）
- 方向：多空雙向評估
- 槓桿：75x（固定）

**Loop D** — 多時框共振評分（四層架構）
- 頻率：每 1 秒
- 來源：BingX 跌幅第一的幣種
- 方向：做多（LONG）
- 進場決策：score ≤ 2 不進場；score 3–4 標準倉；score ≥ 5 加碼（addPosition = true）

**Loop E** — 抄頂偵測（評分制）
- 頻率：每 1 秒
- 來源：BingX 漲幅第一的幣種
- 方向：做空（SHORT）
- 門檻：評分 ≥ 75 分才開單

---

## 二、Loop A 進場條件（三階段）

### 第零階段：4h Market Regime 判定

在進入 1h/15m 評估前，先判定 4h 市場狀態（regime），並依 regime 決定後續過濾門檻。

**Regime 判定規則**
- ADX(14) > 35 或 R²(近20根) > 0.8 → `strong_trend`（強趨勢）
- ADX(14) 20–35 或 R² 0.6–0.8 → `weak_trend`（弱趨勢）
- ADX(14) < 20 且 R² < 0.6 → `ranging`（橫盤，不進場）

**多單（LONG）— 強趨勢路徑**
- 4h RSI(14) > 56
- 4h 收盤價 > EMA(89)

**多單（LONG）— 弱趨勢路徑**
- 4h RSI(14) > 50
- 4h 收盤價 > EMA(89) × 0.98（允許貼近均線）

**多單（LONG）— 備用路徑（reversal，適用弱/強趨勢）**
- 前兩根 4h RSI 均 < 40（超賣確認）
- 當根 RSI 連升（rsi14 > rsiPrev1 > rsiPrev2）
- 4h 收盤價 > EMA(89)（突破結構）

**空單（SHORT）— 強趨勢路徑**
- 4h RSI(14) < 45
- 4h 收盤價 < EMA(89)

**空單（SHORT）— 弱趨勢路徑**
- 4h RSI(14) < 50
- 4h 收盤價 < EMA(89) × 1.02

> 說明：橫盤（ranging）**不直接擋掉**，改為放行至後續型態偵測路徑（1h + 15m 形態評分）。若型態評分未達標仍不進場。`is4hReversal` 旗標供後續邏輯參考。

### 第一階段：1h 動能（依 regime 分路徑）

**強趨勢路徑（strong_trend）**

多單（LONG）：
- EMA(34) > EMA(89)（中期趨勢向上）
- RSI(14) > 52（動能偏多）
- 過去 5 根內 RSI 曾低於 50（確認是回調後反彈，非追高）
- 當根成交量 > 20 根均量 × 1.4x

空單（SHORT）：
- EMA(34) < EMA(89)
- RSI(14) < 48
- 過去 5 根內 RSI 曾高於 50
- 當根成交量 > 20 根均量 × 1.4x

**弱趨勢路徑（weak_trend）**

多單（LONG）：
- EMA(34) > EMA(89)（方向確認）
- RSI(14) > 50（門檻較低）
- 過去 5 根內 RSI 曾低於 50
- 當根成交量 > 20 根均量 × 1.2x（量能門檻較低）

空單（SHORT）：
- EMA(34) < EMA(89)
- RSI(14) < 50
- 過去 5 根內 RSI 曾高於 50
- 當根成交量 > 20 根均量 × 1.2x

**15m 形態評分（多單，≥ 5 分通過）**
- BOS 突破：收盤突破近 20 根高點 → +3
- 量價齊升：收陽 + 量 > 均量 1.5x → +2
- RSI 動能：RSI > 55 且向上 → +2
- 看漲吞沒：當根陽線完全包覆前根陰線 → +2
- 蓄力爆發：前 3 根縮量後放量 > 2x → +2
- 均線多頭排列：價格 > EMA20 > EMA50 → +1
- 錘子線：下影線 > 實體 2x，收陽 → +1

**15m 形態評分（空單，≥ 5 分通過）**
- BOS 向下突破：收盤跌破近 20 根低點 → +3
- 量價齊跌：收陰 + 量 > 均量 1.5x → +2
- RSI 下行：RSI < 45 且向下 → +2
- 看跌吞沒：當根陰線完全包覆前根陽線 → +2
- 蓄力爆跌：前 3 根縮量後放量 > 2x，收陰 → +2
- 均線空頭排列：價格 < EMA20 < EMA50 → +1
- 射擊之星：上影線 > 實體 2x，收陰 → +1

**錨點過濾（新增）**
- BOS 突破 或 均線排列，至少一個成立
- 若兩者都不成立（例如純量價 + RSI 組合），直接跳過
- 目的：過濾缺乏結構支撐的低品質訊號

## 三、Loop E 空頭評分制（滿分 100，門檻 ≥ 75）

開單前需通過以下評分，**總分 ≥ 75 才執行開單**。

### 評分項目

- BOS 向下突破：15m 收盤價 < 近 20 根最低點 → +20
- 量價齊跌：當根收陰 + 成交量 > 20 根均量 × 1.5 → +15
- RSI 下行：RSI(14) < 45 且 < 前一根 RSI(14) → +15
- 均線空頭排列：收盤 < EMA20 且 EMA20 < EMA50 → +10
- 射擊之星：上影線 > 實體 × 2，下影線 < 實體 × 0.5，收陰 → +10
- 看跌吞沒：前根收陽，當根收陰，當根開盤 ≥ 前根收盤，當根收盤 ≤ 前根開盤 → +10
- RSI 三線空頭排列（1h）：RSI(6) < RSI(12) < RSI(24) 且三線全 < 50 → +10
- MACD 死叉：MACD 線從上方穿越 Signal 線 → +5
- MACD 柱負（無死叉時）：MACD Histogram < 0 → +3
- BB 中軌以下：布林帶位置百分比 < 50% → +5

### 強度分級

- 評分 ≥ 90 → HIGH 🔥，槓桿 10x
- 評分 75–89 → MED ⭐，槓桿 7x
- 評分 < 75 → 不開單

### 自動排除條件

- RSI(14) < 30（超賣區，不追跌）
- SL 距離 > 8%（風險過大）
- 同幣種已有持倉且方向相同

---

## 四、持倉管理規則

**同幣種有持倉時**
- 同方向訊號 → 跳過，不加倉
- 反向訊號成立 → 換倉（先止盈平倉，再開反向新倉）

**反向換倉條件（全部滿足才執行）**
- 持倉時間 ≥ 15 分鐘
- 現有倉位損益 > -3%
- 反向訊號通過三階段過濾

---

## 五、開單規則

- 保證金：固定 3 USDT/筆
- 槓桿：BTC/ETH 75x；其他幣種 HIGH=10x / MED=7x / LOW=5x
- 方向：多空雙向（LONG / SHORT）
- 冷卻機制：無時間冷卻，以持倉狀態控制（有持倉不重複開同方向）
- SL 上限：距離 > 4%（Loop A）/ > 8%（Loop D/E）跳過

---

## 六、不進場條件

**Loop A 專屬**
- 4h Regime 為橫盤（ranging）且 1h/15m 型態評分未達標（橫盤不直接擋掉，由後續型態決定）
- 4h RSI 不符合方向（多 ≤ 55 / 空 ≥ 45）（僅適用 strong_trend / weak_trend 路徑）
- 4h 收盤價在 EMA89 錯誤側（僅適用 strong_trend / weak_trend 路徑）
- 1h EMA34/89 排列不符合方向
- 1h RSI 不符合方向（多 ≤ 52 / 空 ≥ 48）
- 1h 量能不足（< 均量 1.4x）
- 15m 形態分數 < 5
- 15m 無 BOS 且無均線排列（缺乏結構錨點）
- SL 距離 > 4%
- 第二階段指標共振分數 < 5
- 同幣種同方向已有持倉
