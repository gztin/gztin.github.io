# 止盈/止損管理（Loop C - Exit Management）

> 最後更新：2026-04-25
> 架構變更：Loop C 改為純 SL Fallback 備援，主要出場由 BingX TP/SL 單自動處理
> isPaper 倉位必須有 bingxQty 才受 Loop C 監控；無 bingxQty（API Key 未設定）直接跳過

---

## 執行方式

- 頻率：每 1 秒
- 角色：**備援機制**，只在 BingX 止損單未執行時介入
- 不負責：TP1/TP2/TP3（由 BingX 止盈單自動處理）
- 不負責：移動止損（已移除，由 BingX 固定 SL 單處理）

---

## 主要出場架構

```
進場後同步在 BingX 掛單：
  ├── TP1 = 進場價 ± 1R（50% 倉位）
  ├── TP2 = 進場價 ± 1.618R（30% 倉位）
  ├── TP3 = 進場價 ± 2.618R（20% 倉位）
  └── SL  = 結構低/高點 ± 0.5 ATR

BingX 自動執行，Loop C 不重複干預。
```

---

## 止損（SL）計算

開單時計算 SL，規則如下：

- 多單：SL = 近 20 根 15m K 線最低點 - 0.5 × ATR(14)
- 空單：SL = 近 20 根 15m K 線最高點 + 0.5 × ATR(14)
- SL 距離 > 4%（Loop A）→ 跳過此訊號，不開單
- SL 距離 > 8%（Loop D/E）→ 跳過此訊號，不開單

---

## 止盈（TP）計算

以 R（風險距離）為基礎，開單時同步設定三個止盈委託：

- TP1 = 進場價 ± 1.0R → 50% 倉位出場
- TP2 = 進場價 ± 1.618R → 30% 倉位出場（黃金比例）
- TP3 = 進場價 ± 2.618R → 20% 倉位出場（最終目標）
- R = |進場價 - SL|

TP 委託由 BingX 自動執行，Loop C 不重複檢查。

---

## isPaper 倉位處理規則

| 狀態 | 行為 |
|------|------|
| `isPaper: true` + `bingxQty` 有值 | 查詢 BingX 模擬盤實際持倉，以持倉消失為出場依據 |
| `isPaper: true` + `bingxQty` 為空（API Key 未設定） | **直接跳過，不做任何處理** |

> 說明：無 bingxQty 代表用戶尚未設定 API Key，無法開模擬盤倉位，Loop C 不對此類記錄執行任何出場邏輯。

---

## Loop C SL Fallback 觸發條件

以下任一條件成立，Loop C 執行市價平倉：

**條件一：現價穿越 SL（BingX 止損單備援）**
- 多頭：現價 ≤ SL
- 空頭：現價 ≥ SL
- 說明：正常情況下 BingX 止損單會先觸發，Loop C 作為最後防線

**條件二：超時深度虧損（防長時間套牢）**
- 持倉超過 48 小時 且 虧損 ≥ 9%
- 說明：避免倉位長期套牢佔用保證金

**條件三：BingX 持倉已消失（自動清理）**
- 查詢 BingX 實際持倉量 < 原始數量 10%
- 代表 BingX 已自動執行 TP 或 SL 出場
- Loop C 同步清理 botState，推送出場通知

**條件四：TP1 達標後 EMA20 跌破出場（取代固定 BE）**
- 偵測到 BingX 倉位剩餘約 50%（TP1 已觸發）後啟動
- 每秒監控 15m K 線：收盤跌破 EMA20 且收陰（多單）/ 收盤突破 EMA20 且收陽（空單）
- 觸發後市價平倉剩餘倉位
- 說明：比固定成本價 BE 更有彈性，讓倉位跟著趨勢走，反轉才出場

---

## 出場執行流程

1. 偵測到觸發條件
2. 推送出場通知（含進出場價、損益 %、觸發原因）
3. 呼叫 BingX API 市價平倉（closeOrder）
4. 計算損益 U 數：pnlPct% × 本金 × 槓桿
5. 將記錄寫入 botState.history
6. 從 botState.activeStrategies 刪除

---

## 與舊版的差異

| 項目 | 舊版 | 新版 |
|------|------|------|
| 移動止損 | TP1 後啟動 ATR 追蹤 | 移除，由 BingX 固定 SL 處理 |
| Loop B 觸發平倉 | 反轉權重 > 6 直接平倉 | 移除，改為只推通知 |
| 超時條件 | 30 分鐘 + 虧損 9% | 48 小時 + 虧損 9% |
| BingX 同步 | 無 | 新增持倉量比對，自動清理狀態 |
| isPaper 無 bingxQty | 純價格模擬（SL/TP/超時觸發） | 直接跳過，不處理 |

## 保證金與槓桿

- BTC、ETH → 75x，保證金 3 USDT
- 其他幣種 HIGH → 10x，保證金 3 USDT
- 其他幣種 MED → 7x，保證金 3 USDT
- 其他幣種 LOW → 5x，保證金 3 USDT
