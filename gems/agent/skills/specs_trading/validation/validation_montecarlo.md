# Monte Carlo（蒙地卡羅模擬）

## 目的

量化策略在**最壞情況**下的回撤和連敗風險，用於決定實盤所需的最低本金。

---

## 核心概念

交易的實際發生順序是隨機的。蒙地卡羅把歷史交易的損益打亂 10,000 次，模擬未來可能出現的各種序列，統計回撤和連敗的分佈。

```
實際交易序列：+2U, -3U, +1U, +4U, -2U, +3U ...

打亂後序列1：-3U, +4U, -2U, +1U, +3U, +2U ...  → 計算最大回撤
打亂後序列2：+4U, -2U, +3U, -3U, +1U, +2U ...  → 計算最大回撤
...（重複 10,000 次）

統計 10,000 次的回撤分佈 → 得出 95th percentile 最大回撤
```

## 輸出範例

```
【Monte Carlo】
  最大回撤（50th/75th/90th/95th）: -12.55 / -15.14 / -18.04 / -20.10U
  最大連敗（50th/90th/95th）: 3 / 4 / 4 連敗
  建議最低本金: 60.3U（95th回撤 × 3倍緩衝）
```

---

## 指標解讀

### 最大回撤分佈

| 百分位 | 意義 |
|--------|------|
| 50th（中位數） | 典型情況下的最大回撤，一半的模擬低於此值 |
| 75th | 75% 的模擬低於此值 |
| 90th | 90% 的模擬低於此值 |
| **95th** | **最壞 5% 情況的最大回撤，用於計算建議本金** |

### 最大連敗分佈

- 50th：正常情況下的連敗次數
- 95th：最壞情況下的連敗次數，用於心理準備

### 建議最低本金

```
建議最低本金 = 95th 最大回撤 × 3 倍緩衝

範例：95th 回撤 = -20U → 建議本金 = 60U
```

3 倍緩衝的意義：即使遇到最壞情況，帳戶還有 2/3 的資金繼續運作，不會因為資金不足被迫停止。

---

## 重要限制

**蒙地卡羅的獲利機率 = 100% 不代表策略一定賺錢**

打亂順序不影響總損益（加法交換律），所以只要歷史回測是正的，10,000 次模擬的最終損益都一樣。這個數字沒有意義。

**真正有價值的是回撤和連敗分佈**，這些會因為順序不同而變化，反映了真實的路徑風險。

---

## 通過標準

蒙地卡羅本身不判斷通過/失敗，而是提供風險數字供決策：

- 95th 最大回撤 < 帳戶資金的 30% → 風險可接受
- 95th 最大連敗 ≤ 5 連敗 → 心理壓力可承受
- 建議最低本金 < 實際帳戶資金 → 可以實盤

---

## 注意事項

- 樣本數 < 30 筆時，結果參考性有限
- 蒙地卡羅假設每筆交易獨立，但實際上連敗往往集中在特定市場狀態
- 真實的最大連敗可能比 95th 更高，因為市場狀態有時序相關性
- 建議本金是下限，實際操作建議留更多緩衝
