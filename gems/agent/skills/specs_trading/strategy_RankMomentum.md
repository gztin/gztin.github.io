# 策略規範：排行榜動能偵測 (Loop F)

本規範定義了基於交易所排行榜 (BingX Top 30) 的動能偵測與走勢穩定度分析邏輯，旨在排除雜訊並抓取高品質起漲標的。

## 1. 偵測機制概述 (Overview)
Loop F 每 30 秒對排行榜前 30 名進行快照比對，結合「排名變動」與「K 線技術面分析」進行訊號分級。

## 2. 訊號類別判定 (Signal Categories)

### 🔥 強力推薦 (Super Signal)
*   **判定標準**：同時滿足 **[爆發條件]** 與 **[穩定條件]**。
*   **特性**：兼具名次竄升動態與健康的技術面結構，成功率最高。
*   **推送格式**：含雙重分析數據的詳細卡片。

### 🔍 蓄勢預警 (Momentum Alert)
*   **判定標準**：
    1.  **排名變動**：連續 2 輪以上名次爬升。
    2.  **漲幅門檻**：24H 漲幅 > 3%。
    3.  **動能星數**：15m K 線技術評級自 `analyzeSignalStrength` 取得 ≥ 2⭐。
*   **特性**：代表市場熱度集中，資金正在快速拉升排名。

### 🐢 穩定爬升 (Steady Climb)
*   **判定標準**：
    1.  **結構穩定**：15m K 線近 20 根的線性回歸 R² > 0.6。
    2.  **斜率方向**：線性回歸斜率 (Slope) 為正。
    3.  **低點遞增**：具備 Higher Lows 結構 (趨勢健康)。
    4.  **漲幅門檻**：24H 漲幅 > 3%。
*   **特性**：代表慢牛走勢，適合穩健型進場。
*   **推送格式**：彙整成清單輸出，減少單獨訊息洗頻。

## 3. 績效驗證開倉邏輯 (Performance Tracking)

Loop F 偵測到穩定爬升清單後，自動對「領跑者」執行模擬倉開倉：

### 領跑者選取（每輪最多 2 個）
- **結構最穩**：R² 最高的標的
- **成長最強**：斜率（slopePct）最高的標的
- 若兩者為同一標的，合併為「結構最穩+成長最強」，只開一倉

### 開倉門檻
- 至少 2 項指標達到本輪群體平均（R²、斜率、低點遞增數，任兩項 ≥ 平均）
- 合約必須可交易（`getMaxLeverage` 回傳 ≥ 2）
- 同標的已有持倉則跳過
- **防追高**：排行榜前 3 名不開倉（rank ≤ 3 直接跳過）

### 槓桿設定
- `leverage = floor(maxLeverage × 0.5)`，以最大槓桿的一半執行

### 開倉記錄
- `entrySnapshot.role`：記錄領跑者角色（結構最穩 / 成長最強 / 兩者兼具）
- `loopType: 'loopF'`，`hidden: true`（不推送給用戶，靜默追蹤）

## 4. 技術分析細節 (Technical Details)

### A. 動能評級 (analyzeSignalStrength)
*   **RSI 底部抬升** (2⭐)：RSI(14) 連續上升且未進入超買區。
*   **布林帶壓縮** (2⭐)：帶寬縮至近期低點，預示即將變盤。
*   **成交量蓄積** (1⭐)：放量大於均量 1.5x 以上。

### B. 穩定度分析 (detectSteadyClimb)
*   使用 **線性回歸 (OLS)** 計算收盤價走勢。
*   **R² (判定係數)**：衡量走勢與直線的擬合度，數值越高代表爬升過程越平穩（無劇烈震盪）。

## 4. 冷卻與頻率控制 (Cooldown)
*   **爆發性訊號 (🔍/🔥)**：同一幣種冷卻 30 秒，捕捉熱點動態。
*   **穩定性訊號 (🐢)**：同一幣種冷卻 5 分鐘，避免長趨勢中重複推送。
*   **報表**：每 5 分鐘推送一次統計彙總，監控系統掃描頻率。
