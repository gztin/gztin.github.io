# 儀表板使用說明 (Interface Guide)

Gems 訊號儀表板提供直觀的數據監控，幫助使用者快速過濾優質訊號並分析歷史勝率。

## 1. 核心區塊說明

### 📊 統計統計卡片 (Score Cards)
- **分數段區分**：分為 60-70、70-80、80-90、90-100 四個等級。
- **勝率顯示**：顯示該分數段在「當前選中週期」下的達標率。
- **數據彙整**：顯示已達標筆數、評估中筆數以及總推送筆數。

### 🛠️ 工具列 (Toolbar)
- **時間週期**：切換評估的時間長度（15m / 30m / 1h / 4h）。切換後，勝率和表格內容會同步更新。
- **進場門檻**：篩選顯示特定分數以上的訊號（例如只看 80 分以上的精選訊號）。
- **📖 達標標準說明**：點擊可隨時查看各週期的漲幅門檻標準。
- **🌙/☀️ 主題切換**：點擊標題旁的 Icon 可快速在深色與淺色模式間切換。

### 📝 訊號明細表格
- **資產項目**：移除幣種後的 USDT 名稱。
- **進場分數**：該訊號發出時的綜合評分。
- **價格變動**：顯示進場後到評估時間點的累積漲幅。
- **推送時間**：採用台北時間 (Asia/Taipei) 顯示。

## 2. 關鍵過濾機制
- **自動過濾**：表格預設**僅顯示「已達標」**的訊號，過濾掉震盪或失敗的樣本，方便使用者快速覆盤強勢標的。
- **延遲顯示**：為了確保數據準確，新發出的訊號若未滿 15 分鐘（最短評估週期），將不會顯示在表格中。

---

## 3. 部署資訊
- **訪問路徑**：`https://[your-domain]/gems/public/signal_dashboard.html`
- **數據來源**：後端機器人每 15 分鐘自動更新一次 `signal_journal.json`。
